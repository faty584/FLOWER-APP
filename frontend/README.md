# FLOWER-APP

A responsive flower management web application built with React.

## Features

- **Admin Panel**: Manage flowers with add and delete functionality.
- **Flower List**: View all flowers from the backend, each displayed in a professional, responsive card with image, name, category, price, and description.
- **Add Flower**: Admins can add new flowers with image upload, name, category, description, and price.
- **Delete Flower**: Admins can delete flowers directly from the list.
- **Responsive Design**: Works beautifully on desktop, tablet, and mobile.
- **Backend Integration**: Connects to a backend API for all flower data operations.

## Technologies Used

- React (frontend)
- Axios (API requests)
- CSS (responsive styling)
- Node.js/Express or similar (backend API)

## How to Run

1. **Install dependencies:**
2. **Start the frontend:**
   - Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Start the backend:**
   - Go to your backend folder and run the backend server (e.g., `npm start` or `node server.js`).

4. **API Endpoint:**
   - The frontend expects the backend API at `/api/flowers` (update the URL in the code if your backend runs elsewhere).

## Folder Structure

- `/src/Components` - Navbar, Footer, and other shared components
- `/src/Pages` - Flower.js (list), Addflower.js (form), and related CSS files
- `/src/assets` - Images and icons
